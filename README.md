How to Run
Clone the Repository
git clone https://github.com/Vishnu01-new/code-soft.git

Navigate to the Repository
cd code-soft

Run a Project

Navigate to the project folder you want to run.

For example:

cd Task-1-Number-Game


Compile the Java program:

javac NumberGame.java


Run the program:

java NumberGame


The same process can be followed for the other projects by navigating to their respective folders and using the appropriate Java file and class name.
